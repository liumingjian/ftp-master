# Office editing through Chrome and desktop WPS, with server-held Edit Permits

Milestone 1 includes Office editing on macOS in Google Chrome with desktop WPS. The User starts editing in the ftp-master file browser, saves in WPS, then returns to Chrome to submit the saved document as a new File Version. Chrome does not support the NPAPI integration used by Qaxbrowser. A prototype round trip on macOS arm64 completed this workflow for DOCX and XLSX against a running ftp-master.

## Chrome and WPS

- The dedicated Office Plugin ships from the `ftp-master` branch of `liumingjian/wps-plugin`. It uses a Manifest V3 extension with its own fixed ID, exactly one configured ftp-master origin, and a macOS Native Messaging host registered for that extension ID. Local acceptance uses an unpacked extension and a documented host setup. The installation channel for a broader Chrome rollout is a separate decision.
- The file browser stays open. The extension handles explicit edit entries, starts an edit for the selected File Version using the User's session, and sends the returned Document Gateway URL to the native host. The host retrieves the bytes without the session cookie and stages a private local Work Copy. The extension confirms complete delivery with a same-origin session-authenticated request before the host opens that Work Copy in desktop WPS.
- The User saves to disk in WPS and explicitly submits from Chrome. The host supplies a stable copy of the saved bytes through bounded messages that support the full 25 MiB limit. The extension posts those bytes to the returned save URL using the User's session and reads the committed File Version from the save receipt. Pending bytes remain recoverable after closing or reopening Chrome or WPS. Confirmed failures allow explicit retry. If the server outcome is unknown, the client retains the bytes and requires reconciliation before resubmission.
- The macOS acceptance matrix covers DOC, DOCX, WPS, XLS and XLSX, including close and recovery, the full supported file size and overlapping edits. Forced Writer revision tracking and spreadsheet change history on Mac require a product decision. If either is required for Mac rollout, verify that behavior on the target WPS build before rollout.
- The existing Kylin, Qaxbrowser and WPS requirements apply to that deployment, including embedded editing, forced Writer revision tracking and spreadsheet change history. RoadFlow has its own build and extension ID.

## Server contract

- The application checks Modify, the recorded format, and the 25 MiB limit at edit start. It records an open-for-edit Audit Event and issues a short-lived Edit Permit bound to the User, file and File Version. The response supplies the Document Gateway, delivery-check and save URLs. The plugin uses these URLs as returned.
- The Document Gateway serves the exact bound version against an unused, unexpired permit and records delivery after a complete response. The delivery check requires the permit owner's session. Saves require that session, completed delivery and current Modify. Expiry limits initial retrieval. A delivered permit can support repeated saves.
- The Writer multipart shape contains `filedata`, `md5sum` and `filename`. The ET shape contains one `file` part with an empty filename, or a single `file` value. The server verifies the Writer checksum, accepts valid same-family serializations, preserves the shared-tree name and records the actual format. It rejects malformed and cross-family content.
- Each accepted save atomically creates one File Version and one Audit Event and returns HTTP 200 with the structured receipt. Rejected saves return non-2xx and create neither. When the permit's base version is older than the latest, the save succeeds and its Audit Event records a Stale Save. Earlier File Versions remain restorable.
- The Office Plugin exposes a page-visible presence marker on the configured origin. The application enables the edit entry when the plugin is present and the User has Modify on a supported File Version within the size limit. Ordinary downloads remain outside the edit-entry contract.
