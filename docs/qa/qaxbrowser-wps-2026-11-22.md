# 2026-11-22 Qaxbrowser 与 WPS 验收

银河麒麟桌面操作系统 V10 SP1 ARM64，Linux `5.4.18-167-generic`，Qaxbrowser `1.0.46402.2-1`（Chromium `102.0.5005.200`），WPS `12.1.2.26885.AK.preread.sw`。浏览器注册了 `application/x-wps` 和 `application/x-et`，实际挂载的 Writer 和 ET 对象均提供 `Application` 方法。

应用基线为 `codex/spec-1@d3afce2`。发布的扩展 `53cf43d` 在本机可以打开 XLSX，但编辑后保存失败。下表使用插件工作树中已有的 `cd78876` 修复。验收地址为 `http://127.0.0.1:48833`，使用独立的 PostgreSQL、Redis、MinIO 和 Vite 实例。当前账号无法访问 Docker socket，Compose 文件通过了配置校验。

## 原生文件验收

| 打开的文件 | 原始版本 | 保存后的版本及实际格式 | 下载字节 | 保存／重开审计 |
| --- | ---: | --- | --- | --- |
| DOCX | 40 | 43 · DOC | CFB/OLE | 259／261 |
| DOC | 44 | 49 · DOC | CFB/OLE | 291／294 |
| XLSX | 3 | 53 · XLSX | OOXML ZIP | 308／310 |

三份文件均在嵌入式编辑器修改并保存，再从原目录重开，读回各自的编辑内容。文件版本 API、保存审计、重新打开审计以及下载字节与表中记录一致。Writer 将测试 DOCX 序列化为 DOC，应用保留原文件名。编号来自这次的临时验收库。

- DOCX 和 DOC 重开后各有一条 Writer 修订。ET 重开后启用了共享编辑、保留变更历史和屏幕高亮，版本 53 的 OOXML 修订日志含本轮改动的单元格内容。
- DOCX 和 XLSX 在会话退出后保存失败，编辑内容保留且文件版本数不变。恢复同一用户会话后重试保存成功。
- 过期和已交付的 XLSX 许可都使编辑验证失败，保存按钮禁用，失败后的界面移除了 WPS 对象，两种情况均未产生保存审计。
- XLSX 两个编辑页从版本 53 打开，分别保存为 59 和 60。两个版本均保留，第二次保存的审计有 `staleSave: true`，从原目录重开读到第二份编辑。RoadFlow 配置完成后，同一测试用版本 60 再次验证，产生 71 和 72。
- 复制本机的 RoadFlow WPS Editor 1.0.20 到隔离浏览器配置后，RoadFlow 在本机 OA 模拟器打开并保存了原生 Writer 文档，OA 页面无 ftp-master 扩展标记。配置 RoadFlow 后，ftp-master 仍完成 XLSX 的原生编辑、保存和重开。客户 OA 与生产 ftp-master 地址尚未纳入本轮验收。

## 应用验收

- Qaxbrowser 在 1280 像素和 390 像素宽度下均可查看完整文件表及操作列。390 像素下目录抽屉可打开并用 Escape 关闭，文件详情可打开，在线编辑入口可见。
- 普通用户只能搜索到有浏览权限的文件。移动入口依据结果的源父目录 Delete 权限，即使文件本身有 Delete 权限也不会改变该判断。
- 受委派用户可查看其管理范围内各节点的直接授权数，个人授权达到 10 条时目录树显示警示。保存草稿后计数更新，继承项仍显示锁定及来源，范围外的直接授权查询返回 403。
- `make check-generated test-unit` 和前端生产构建通过。插件的 20 条浏览器测试通过。应用的 34 条浏览器用例均有通过结果，其中 33 条在最后一轮全量运行中通过，文本冲突用例在该轮等待超时，单独重跑并将断言等待延长到 15 秒后通过。

## 本机 Compose 与交互复验

- 本机 Docker Compose 启动应用、PostgreSQL、Redis 和 MinIO，更新后的应用通过健康检查。奇安信浏览器安装并重新加载了对应的专用扩展。
- 在实际 Qaxbrowser 和 WPS 中点击 DOC、DOCX 和 XLSX 文件名可直接预览。Writer 启用只读保护，ET 以只读模式打开。用已完成交付的预览许可提交保存请求返回 HTTP 403。
- 行尾铅笔直接打开编辑页，点击「返回文件列表」回到原目录。空闲时上传状态行高度为零，上传完成提示仍按原时限消失。Office 和上传的 12 条 Playwright 用例均在 Compose 上通过。
